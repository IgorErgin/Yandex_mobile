# 🚀 Домашнее Задание №1: "Анкета Пользователя" (Jetpack Compose)

## 🎯 Цель Проекта
Проект разработан в рамках первого домашнего задания и направлен на закрепление базовых навыков работы с основными элементами Jetpack Compose:
* **Состояние:** `remember`, `mutableStateOf`, `rememberSaveable`.
* **Модификаторы:** `Modifier`, `padding`, `fillMaxWidth`.
* **UI-компоненты:** `Text`, `TextField`, `Button`, `Image`, `Checkbox`, `RadioButton`, `Slider`.
* **Верстка:** Адаптивное использование `Column`, `Row`, `Box`.

---

## ✅ Выполненные Требования

### 1. Основные Элементы Анкеты

| Элемент | Реализация | Компоненты |
| :--- | :--- | :--- |
| **Поле ввода имени** | Локальное состояние с `rememberSaveable`. | `TextField` |
| **Выбор возраста** | Отображение текущего значения рядом с ползунком. | `Slider` + `Text` |
| **Выбор пола (м/ж)** | Выбор единственного варианта. | `Row` + `RadioButton` |
| **Подписка на рассылку** | Чекбокс с текстом «Хочу получать новости». | `Checkbox` |
| **Кнопка «Отправить»** | Отображает краткую сводку данных внизу экрана. | `Button` |
| **Аватар/Изображение** | Вставлено изображение по умолчанию. | `Image` |

### 2. Требования к Коду и Дизайну

* **Состояние:** Все поля используют `rememberSaveable` для сохранения данных при пересоздании активности (например, при смене ориентации).
* **Верстка:** Элементы размещены вертикально (`Column`) и выровнены по центру экрана.
* **Стилизация:** Применены базовые модификаторы (`Modifier.padding`, `fillMaxWidth`) для читаемого и аккуратного интерфейса.
* **Ресурсы:** Все строки для отображения текста на экране взяты из `strings.xml`.

## 💡 Выполнение Дополнительных Заданий

Проект полностью соответствует дополнительным требованиям:

1.  **Базовая Валидация:** Кнопка **«Отправить» заблокирована** до тех пор, пока поле ввода **Имени не заполнено**.
2.  **Предпросмотр (@Preview):** Добавлены `@Preview` для **тёмной** и **светлой** темы.
3.  **Адаптивность (Портрет/Ландшафт):** Интерфейс корректно отображается и перестраивается как в **портретной**, так и в **ландшафтной (альбомной)** ориентации.
